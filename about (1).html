About QuickNotes

QuickNotes is a simple note-taking app for jotting down ideas, reminders, and to-do items before you forget them. It is designed to stay out of your way, so you can write first and organise later.

How to use QuickNotes

  1. Open QuickNotes and click the "New note" button.
  2. Type a title and write your note in the text area.
  3. Click "Save" to store the note.
  4. Select any saved note from the list to read or edit it.

Features

  • Create notes with one click
  • Edit and delete notes at any time
  • Search through all your notes
  • Keyboard shortcuts for common actions

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + F Search your notes
